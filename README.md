# TT's Calculator v1.0

A command-line calculator written in Python that supports:

- Addition
- Subtraction
- Multiplication
- Division
- Exponents
- Modulo
- Calculation history
- Reusing the previous answer (`ans`)
- Input validation

## Requirements

- Python 3.10 or newer

## Installation

1. Clone the repository:

```bash
git clone https://github.com/tentatime07/proj1.calculator.git
```

2. Navigate into the project folder:

```bash
cd proj1.calculator
```

3. Run the program:

```bash
python calculator.py
```

or

```bash
python3 calculator.py
```

(depending on your operating system)
