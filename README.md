# TT's Calculator v1.0
Youtube walkthrough: https://www.youtube.com/watch?v=_V_4-t3f00E

A command-line calculator written in Python that supports:

- Addition
- Subtraction
- Multiplication
- Division
- Exponents
- Modulo
- Calculation history
- Reusing the previous answer (`ans`)
- Input validation

## Future Improvements for v1.1

- Save history to a file
- Support chained calculations
- Graphical user interface
- Scientific functions
